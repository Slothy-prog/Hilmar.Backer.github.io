## Projects
My most recent project, a mock version of a social media platform where a user can realize how they would stumble into a information bubble through the machinations of their personalized algorithm. My role in this project was Front-end Developer, I made the front-end together with 2 of my 4 groupmates. The inspiration for the design is social media platforms like X and Instagram, with clearly visible and easy to understand buttons and clear borders around all the posts. I paid close attention to making sure everything was easy to see, read and understand.

### Elections
In this project we used the XML files provided by the Dutch government to create our own website showcasing the data in those files. It included numerous functions that allowed a user to look for certain data and compare it. The comparisons could be done by year, municipality, party or amount of votes. My role here was to build the various functions for the municipal data, this includes the back-end and the front-end work but also the service layers.
